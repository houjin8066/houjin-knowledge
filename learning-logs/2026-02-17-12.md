### 3. 三种核心架构模式

#### Hierarchical（层级式）
- 协调者 agent 分配任务给专业 worker agents
- 适用：复杂工作流、金融对账、合规审计
- 案例：Genentech 实验设计从 6 周缩短到 3 天

#### Peer-to-Peer（对等式）
- 自治 agents 直接协作，无中心协调
- 适用：分布式系统、实时优化、车队管理
- 案例：Amazon 用 P2P agents 迁移 1000 个应用（6 个月 vs 预计 3 年）

#### Federated（联邦式）
- 区域 agent 集群通过网关协调
- 适用：多区域部署、数据主权、混合云
- 优势：数据留在区域边界内（GDPR 合规）

### 4. Agent 通信协议

#### MCP (Model Context Protocol) - Anthropic
- 通用接口连接 AI 应用到数据源和工具
- 语言无关、双向通信、基于范围的权限
- 已成为企业多智能体工具共享的事实标准

#### ACP (Agent Communication Protocol)
- 消息类型：REQUEST, INFORM, PROPOSE, CONFIRM/REJECT, QUERY
- 定义直接 agent-to-agent 通信格式

#### ANP (Agent Negotiation Protocol)
- 阶段：CFP → 提案提交 → 评估 → 授予 → 执行监控
- 用于动态资源分配、负载均衡、成本优化
