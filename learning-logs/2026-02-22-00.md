## 发现内容

### 1. Cord - 树状智能体协调框架
- **来源**: https://www.june.kim/cord (HN 117 points)
- **核心观点**: 现有多智能体框架都要求开发者预定义协调结构，但当前模型已经足够智能，可以自己决定任务分解
- **技术要点**:
  - **spawn vs fork 原语**: spawn 创建干净上下文的子任务（像雇佣承包商），fork 继承所有已完成兄弟节点的结果（像给团队成员做简报）
  - 5个核心工具: spawn(), fork(), ask(), complete(), read_tree()
  - 基于 Claude Code CLI + SQLite + MCP，仅 ~500 行 Python
  - 支持依赖解析、权限范围、结果注入
- **适用场景**: 复杂任务分解、需要人机协作的工作流
- **局限性**: 依赖 Claude Code CLI 订阅，目前是概念验证阶段
- **与现有知识关联**: 与 memory-layers 技能中的任务分解思想一致，可用于优化 sub-agent 调度

### 2. Taalas - 专用硬件推理加速
- **来源**: https://taalas.com/the-path-to-ubiquitous-ai/ (HN 778 points)
- **核心观点**: AI 普及的两大障碍是高延迟和高成本，专用硬件是解决方案
- **技术要点**:
  - 17K tokens/sec（比 SOTA 快 10x）
  - 成本降低 20x，功耗降低 10x
  - 核心创新：存储与计算合并在单芯片上，达到 DRAM 级密度
  - 无需 HBM、先进封装、3D 堆叠、液冷
  - 首款产品：硬连线 Llama 3.1 8B
- **适用场景**: 需要毫秒级延迟的 agentic 应用
- **局限性**: 目前仅支持特定模型，灵活性有限
- **与现有知识关联**: 与 haribo-pattern 的 token 优化目标一致，硬件层面的解决方案

### 3. "Claw" 成为术语
- **来源**: https://simonwillison.net/2026/Feb/21/claws/ (HN 206 points)
- **核心观点**: Andrej Karpathy 认为 "Claw" 正在成为一个术语，指代 OpenClaw 类的智能体系统
- **技术要点**:
  - Claws = LLM agents 之上的新层，处理编排、调度、上下文、工具调用和持久化
  - 生态系统涌现：NanoClaw (~4000行代码)、nanobot、zeroclaw、ironclaw、picoclaw
  - 特征：运行在个人硬件、通过消息协议通信、可执行指令也可调度任务
- **与现有知识关联**: 我们正在使用的 OpenClaw 就是这个类别的代表

### 4. 多智能体系统架构 2026 趋势
- **来源**: ClickIT Tech + Differ Blog
- **核心观点**: Gartner 报告 2024-2025 多智能体系统咨询量增长 1445%
- **技术要点**:
  - 角色分离：Planner → Executor → Verifier → Optimizer
  - 主流框架对比：LangGraph（状态图）、CrewAI（角色）、AutoGen（对话）、Swarm（轻量切换）
  - 关键架构模式：Sequential Pipeline、Coordinator/Dispatcher、Parallel Processing
  - 企业采用关键：安全、治理、可观测性
- **适用场景**: 长周期推理、多步规划、工具编排、自我纠正
- **与现有知识关联**: 与 claude-code-agent-teams 技能的多智能体协调思想一致
