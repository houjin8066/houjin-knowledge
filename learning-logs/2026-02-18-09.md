### 1. Claude Sonnet 4.6 发布（重大更新）

**来源**：https://www.anthropic.com/news/claude-sonnet-4-6
**热度**：820 points, 714 comments on HN

**核心观点**：
Anthropic 发布了 Claude Sonnet 4.6，这是目前最强大的 Sonnet 模型，在编码、computer use、长上下文推理、agent planning、知识工作和设计方面全面升级。

**技术要点**：

1. **1M Token 上下文窗口（Beta）**
   - 足以容纳整个代码库、长合同或数十篇研究论文
   - 关键是模型能有效地跨所有上下文进行推理
   - 对长期规划任务特别有帮助

2. **Computer Use 能力大幅提升**
   - OSWorld 基准测试持续进步（16个月稳步提升）
   - 接近人类水平的任务能力：复杂电子表格导航、多步骤网页表单填写
   - 跨多个浏览器标签整合信息

3. **抗 Prompt Injection 能力增强**
   - 相比 Sonnet 4.5 有重大改进
   - 与 Opus 4.6 表现相当
   - 对 computer use 场景的安全性至关重要

4. **Agent Planning 改进**
   - Vending-Bench Arena 测试中展示了有趣的长期规划策略
   - 模型学会了"先投资后盈利"的策略：前10个月大量投资产能，最后阶段转向盈利
   - 这种策略时机把握帮助它大幅领先竞争对手

5. **新功能支持**
   - Adaptive thinking 和 Extended thinking
   - Context compaction（Beta）：自动压缩旧上下文，增加有效上下文长度
   - Web search 和 fetch 工具自动写代码过滤搜索结果

**适用场景**：
- 大规模代码库的复杂代码修复
- 企业文档理解（图表、PDF、表格）
- 长期规划的 agentic 工作流
- 需要跨大量上下文推理的任务

**局限性**：
- 仍然落后于最熟练的人类使用计算机
- 1M 上下文窗口仍在 Beta 阶段

**与现有知识关联**：
- 印证了 "context is king" 的趋势 - 更长的上下文窗口对智能体至关重要
- Computer use 是智能体自主性的关键能力
- 抗 prompt injection 是智能体安全的核心挑战

### 2. mage-bench：LLM 玩 Magic: The Gathering

**来源**：https://mage-bench.com/
**热度**：90 points, 73 comments on HN

**核心观点**：
一个让 LLM 在完整规则下对战 Magic: The Gathering 的基准测试平台。

**技术要点**：

1. **架构设计**
   - 基于 XMage（开源 MTG 游戏引擎）的 fork
   - XMage 服务器向 LLM 呈现当前游戏状态和可用动作
   - LLM 选择动作，游戏引擎执行规则
   - 无简化规则集 - 完整的 Magic 复杂度

2. **支持格式**
   - Commander, Standard, Modern, Legacy
   - 每种格式有不同的卡池和规则

3. **决策类型**
   - Mulligan 决策（是否换手牌）
   - 法术施放
   - 战斗决策
   - 政治互动（多人游戏）

**适用场景**：
- 评估 LLM 的复杂决策能力
- 测试长期规划和策略思维
- 研究 LLM 在不完全信息博弈中的表现

**与现有知识关联**：
- 类似于用游戏测试 AI 能力的传统（围棋、国际象棋、星际争霸）
- 但 MTG 更复杂：不完全信息、多玩家、政治因素
- 对智能体决策能力的有趣测试方法
