### 1. Claude Sonnet 4.6 发布（重大更新）

**来源**：https://www.anthropic.com/news/claude-sonnet-4-6
**热度**：644 points, 528 comments

#### 核心观点
Anthropic 发布 Claude Sonnet 4.6，这是目前最强大的 Sonnet 模型，在编码、计算机使用、长上下文推理、智能体规划、知识工作和设计方面全面升级。

#### 技术要点

**1. 性能提升**
- 1M token 上下文窗口（beta）
- 在 Claude Code 中，用户 70% 的时间更偏好 Sonnet 4.6 而非 Sonnet 4.5
- 甚至 59% 的时间更偏好 Sonnet 4.6 而非 Opus 4.5（2025年11月的旗舰模型）
- 定价保持不变：$3/$15 per million tokens

**2. 计算机使用能力（Computer Use）**
- OSWorld 基准测试持续进步（16个月内稳步提升）
- 达到人类水平的任务能力：复杂电子表格导航、多步骤网页表单填写、跨多个浏览器标签协调
- 提示注入防御能力显著提升（相比 Sonnet 4.5）

**3. 智能体规划能力**
- Vending-Bench Arena 测试中展现出有趣的策略：前10个月大量投资产能，最后阶段转向盈利
- 长期规划能力显著提升
- 多步骤任务的一致性和跟进能力更强

**4. 编码能力**
- 更好地阅读上下文后再修改代码
- 整合共享逻辑而非重复代码
- 减少过度工程化和"懒惰"行为
- 更少的虚假成功声明和幻觉

**5. 产品更新**
- 支持 adaptive thinking 和 extended thinking
- Context compaction（beta）：自动总结旧上下文
- Web search 和 fetch 工具自动执行代码过滤搜索结果

#### 适用场景
- 大规模智能体编码工作流
- 复杂文档理解（OfficeQA 达到 Opus 4.6 水平）
- 计算机自动化任务
- 长期规划和多步骤任务
- 前端开发和数据报告

#### 局限性
- 仍落后于最熟练的人类计算机使用者
- 1M 上下文窗口仍在 beta 阶段

#### 与现有知识关联
- 延续了 Anthropic 在 Computer Use 领域的领先地位（2024年10月首发）
- 体现了"小模型追赶大模型"的趋势：Sonnet 级别达到 Opus 级别性能
- 智能体规划能力的提升对多智能体系统有重要意义

### 2. mage-bench：LLM 玩万智牌

**来源**：https://mage-bench.com/
**GitHub**：https://github.com/GregorStocks/mage-bench
**热度**：75 points, 56 comments

#### 核心观点
一个让 LLM 互相对战万智牌（Magic: The Gathering）的基准测试平台。

#### 技术要点
- 基于 XMage 游戏服务器的 fork
- 支持多种赛制：Commander、Standard、Modern、Legacy
- LLM 需要做出完整的游戏决策：调度、施法、战斗、政治
- 使用完整的万智牌规则，无简化

#### 适用场景
- 评估 LLM 的策略规划能力
- 测试长期决策和资源管理
- 多智能体博弈研究

#### 与现有知识关联
- 类似于 AlphaGo/AlphaStar 的游戏 AI 研究
- 但使用 LLM 而非专门训练的模型
- 可用于评估智能体的推理和规划能力
