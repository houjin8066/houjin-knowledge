### 1. Claude Sonnet 4.6 发布（重大更新）

**来源**: https://www.anthropic.com/news/claude-sonnet-4-6 (1240 points, 1111 comments on HN)

**核心观点**:
Anthropic 发布了 Claude Sonnet 4.6，这是目前最强大的 Sonnet 模型，在编码、计算机使用、长上下文推理、智能体规划、知识工作和设计方面全面升级。

**技术要点**:

1. **1M Token 上下文窗口（Beta）**
   - 足以容纳整个代码库、长合同或数十篇研究论文
   - 支持 context compaction：自动总结旧上下文，增加有效上下文长度

2. **Computer Use 大幅改进**
   - OSWorld 基准测试显示 16 个月内持续进步
   - 可处理复杂电子表格导航、多步骤网页表单填写
   - 抗 prompt injection 能力显著提升（与 Opus 4.6 相当）

3. **智能体规划能力**
   - Vending-Bench Arena 测试中展示新策略：前10个月大量投资产能，最后阶段转向盈利
   - 长期规划和策略调整能力显著提升

4. **编码能力**
   - Claude Code 中 70% 用户偏好 Sonnet 4.6 而非 4.5
   - 59% 用户甚至偏好 Sonnet 4.6 而非 Opus 4.5
   - 更好地阅读上下文、整合共享逻辑、减少代码重复
   - 减少过度工程化和"懒惰"行为

5. **新功能**
   - Adaptive thinking 和 Extended thinking 支持
   - Web search/fetch 工具自动写代码过滤搜索结果
   - Code execution、Memory、Programmatic tool calling 正式发布

**适用场景**:
- 大规模智能体编码任务
- 复杂文档理解（OfficeQA 达到 Opus 4.6 水平）
- 长期规划任务
- Computer Use 自动化

**局限性**:
- 最深度推理任务仍推荐 Opus 4.6（代码库重构、多智能体协调）
- Computer Use 仍落后于最熟练的人类

**与现有知识关联**:
- 印证了 Agent 架构中 Computer Use 的重要性
- Context compaction 是解决长上下文问题的实用方案
- 智能体规划能力的提升对多智能体系统有重要意义

### 2. llms.txt 标准 - LLM 友好的网站声明

**来源**: https://annas-archive.li/blog/llms-txt.html (387 points on HN)

**核心观点**:
Anna's Archive 发布了 llms.txt 文件，这是一种新兴标准，让网站向 LLM 声明如何访问其数据。

**技术要点**:
- llms.txt 类似 robots.txt，但面向 LLM
- 提供批量数据下载方式，避免 LLM 触发 CAPTCHA
- 包含 API 访问、Torrent 下载、SFTP 等多种数据获取方式

**适用场景**:
- 智能体需要大规模数据访问时
- 构建知识库和训练数据集
- 网站希望对 LLM 友好但又要防止滥用

**与现有知识关联**:
- 这是智能体与网站交互的新协议
- 可能成为未来智能体工具调用的标准之一
