### 1. 多智能体系统架构 2026 趋势
- **来源**: ClickIT Tech 深度指南
- **核心观点**: 
  - Gartner 报告显示 2024-2025 年多智能体系统咨询量增长 1,445%
  - 单智能体系统在长程推理、多步规划、工具编排方面存在根本局限
  - 角色分离（Planner/Executor/Critic/Verifier）模仿人类团队结构，显著提升可靠性
- **技术要点**:
  - 四种核心角色：规划者、执行者、批评者、验证者
  - 感知-推理-行动-观察循环（OODA/ReAct loops）
  - Checkpointing 机制对生产级系统至关重要
  - 编排层管理任务分配、控制流、状态持久化
- **适用场景**: 企业级工作流、软件开发、数据分析、客户运营
- **局限性**: 协调开销、延迟增加、token 成本可能更高
- **与现有知识关联**: 与 memory-layers 技能的分层思想一致

### 2. Claude Code 规划与执行分离实践
- **来源**: Boris Tane 博客（HN 207 points）
- **核心观点**: 
  - "永远不要让 Claude 在你审核并批准书面计划之前写代码"
  - 规划与执行分离是最重要的原则
  - 使用 markdown 文件作为人机共享的可变状态
- **技术要点**:
  - **四阶段工作流**: Research → Plan → Annotate → Implement
  - **Research 阶段**: 深度阅读代码库，输出 research.md
  - **Plan 阶段**: 生成详细 plan.md，包含代码片段和文件路径
  - **Annotation Cycle**: 人类在 plan.md 中添加内联注释，Claude 更新，重复 1-6 次
  - **关键守卫**: "don't implement yet" 防止过早执行
  - **Todo List**: 实现前生成细粒度任务清单
  - **实现命令模板**: "implement it all. mark completed in plan. do not stop until done."
- **适用场景**: 任何使用 AI 编码工具的开发工作
- **关键洞察**:
  - 最昂贵的失败模式不是语法错误，而是忽略现有系统的实现
  - 单次长会话优于多次短会话（上下文积累）
  - 简短的修正指令比长解释更有效
- **与现有知识关联**: 
  - 与多智能体架构的 Planner/Executor 分离理念完全一致
  - 可应用于 OpenClaw 的 sub-agent 工作流设计
