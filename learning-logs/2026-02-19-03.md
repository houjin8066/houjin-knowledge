### 1. World Models 竞赛 2026 🔥🔥🔥
- **来源**: https://introl.com/blog/world-models-race-agi-2026, https://techcrunch.com/2026/02/18/world-labs-lands-200m-from-autodesk-to-bring-world-models-into-3d-workflows/
- **核心观点**: World Models 被认为是通向 AGI 的关键路径，LLM 存在根本性局限（只学习文本模式，不理解物理现实）
- **技术要点**:
  - **LLM 的天花板**: 数学证明 LLM 无法学习所有可计算函数，必然产生幻觉
  - **World Models 优势**: 理解物理、持久记忆、因果推理、行动规划
  - **三大玩家**:
    1. AMI Labs (Yann LeCun): €500M 融资，€3B 估值，基于 I-JEPA 架构
    2. DeepMind Genie 3: 首个实时交互式通用世界模型，24fps，720p
    3. World Labs (Fei-Fei Li): $1B 融资，发布 Marble 产品，与 Autodesk 合作
  - **NVIDIA Cosmos**: 200万次下载，面向机器人和自动驾驶
- **适用场景**: 机器人训练、游戏、VR/AR、自动驾驶、3D 设计
- **局限性**: 一致性维持时间有限（几分钟）、复杂多智能体交互困难
- **与现有知识关联**: 这是对纯 LLM 路线的重大挑战，智能体架构可能需要融合 World Models

### 2. llms.txt 标准
- **来源**: https://annas-archive.li/blog/llms-txt.html, https://llmstxt.org/
- **核心观点**: 网站应该为 LLM 提供友好的数据访问方式
- **技术要点**:
  - 提供批量数据下载（避免 LLM 破解 CAPTCHA）
  - 提供 API 访问
  - 类似 robots.txt 的 LLM 专用协议
- **适用场景**: 网站与 AI Agent 的交互标准化
- **与现有知识关联**: Agent 工具调用、网页抓取优化

### 3. 前端工具链 for AI 编码
- **来源**: https://cpojer.net/posts/fastest-frontend-tooling
- **核心观点**: 快速反馈循环 + 严格规则 = 更好的 AI 编码质量
- **技术要点**:
  - TypeScript Go (tsgo): 10x 更快的类型检查
  - Oxlint + Oxfmt: 替代 ESLint/Prettier，支持 ESLint 插件
  - @nkzw/oxlint-config: 严格配置让 LLM 写出更好的代码
  - 原则: "Error, Never Warn" - 警告是噪音
- **适用场景**: AI 辅助编程环境配置
- **与现有知识关联**: 晋哥的 AI 辅助编程工作方向

### 4. Mnemom - AI Agent 信任基础设施
- **来源**: https://www.mnemom.ai
- **核心观点**: 为 AI Agent 提供信任协议（Trust Protocols）
- **技术要点**: 支持 Anthropic/OpenAI/Gemini 的信任验证
- **适用场景**: 多智能体系统中的身份验证和信任建立
- **与现有知识关联**: 多智能体协作、Agent 身份认证
