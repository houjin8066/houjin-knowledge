### 1. Claude Code 使用方法：规划与执行分离
- **来源**: https://boristane.com/blog/how-i-use-claude-code/ (HN 526 points)
- **核心观点**: 永远不要让 AI 在你审核并批准书面计划之前写代码
- **技术要点**:
  - 四阶段工作流：Research → Plan → Annotate → Implement
  - 使用 markdown 文件作为"共享可变状态"
  - 注释循环（Annotation Cycle）是关键差异化环节
  - "don't implement yet" 守卫语句防止过早执行
- **适用场景**: 复杂功能开发、需要架构决策的任务
- **局限性**: 简单任务可能过度工程化
- **与现有知识关联**: 与多智能体系统的 Planner-Executor 分离模式一致

### 2. 多智能体系统架构 2026
- **来源**: https://www.clickittech.com/ai/multi-agent-system-architecture/
- **核心观点**: 2026年企业正在大规模采用多智能体架构处理复杂工作流
- **技术要点**:
  - 角色分离：Planner、Executor、Critic、Verifier
  - 环境组件：共享状态、感知-行动循环（OODA/ReAct）
  - 编排层：任务协调、控制流、检查点持久化
  - 单智能体 vs 多智能体：可扩展性、容错性、可观测性
- **适用场景**: 长周期推理、多步骤规划、工具编排、企业级工作流
- **局限性**: 协调开销、延迟增加、成本可能更高
- **关键数据**: Gartner 报告 2024-2025 年多智能体系统咨询量增长 1,445%
