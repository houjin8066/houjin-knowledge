### Step 3.5 Flash - 专为智能体设计的开源基础模型

**来源**：阶跃星辰（StepFun）官方发布

**核心观点**：
Step 3.5 Flash 是目前最强的开源基础模型之一，专门为智能体（Agent）场景优化，强调"Fast Enough to Think, Reliable Enough to Act"——既要快速推理，又要可靠执行。

**技术要点**：

1. **稀疏 MoE 架构**
   - 总参数：196B
   - 每 token 激活参数：仅 11B
   - 核心概念："Intelligence Density"（智能密度）
   - 用更少的计算达到更高的推理能力

2. **MTP-3 (3-way Multi-Token Prediction)**
   - 生成吞吐量：100-300 tok/s（典型场景）
   - 峰值速度：350 tok/s（单流编码任务）
   - 支持复杂多步推理链的即时响应

3. **长上下文优化**
   - 支持 256K 上下文窗口
   - 使用 3:1 SWA（Sliding Window Attention）比例
   - 每 3 层 SWA 配 1 层全注意力层
   - 显著降低长上下文计算开销

4. **智能体能力**
   - SWE-bench Verified: 74.4%
   - Terminal-Bench 2.0: 51.0%
   - 专为长周期任务设计的可扩展 RL 框架

5. **PaCoRe (Parallel Thinking)**
   - 并行思考技术，进一步提升推理性能
   - AIME 2025: 97.3 → 99.9（启用后）
   - HMMT 2025: 94.0 → 98.0

6. **Tool-Augmented Reasoning**
   - 集成 Python 代码执行到 CoT 推理中
   - 支持 80+ MCP 工具编排
   - "Think-and-Act" 协同模式

**适用场景**：
- 编码智能体（Coding Agent）
- 数据分析智能体
- 复杂工作流自动化
- 大规模代码库导航和理解
- 本地部署的隐私敏感场景

**局限性**：
- 虽然是开源模型，但 196B 参数仍需较高硬件配置
- 在某些专业数据分析任务上仍落后于 Claude Opus 4.5
- 需要 Mac Studio M4 Max 或 NVIDIA DGX Spark 级别硬件

**与现有知识关联**：
- 与 DeepSeek V3 的 MoE 架构思路类似，但更注重智能体场景
- MTP 技术是推测解码（Speculative Decoding）的演进
- SWA 长上下文方案与 Mistral 的方案有相似之处
- Tool-Augmented Reasoning 是当前智能体架构的主流方向

## 关键洞察

1. **智能密度是新趋势**：不再追求参数规模，而是追求每参数的智能产出
2. **速度对智能体至关重要**：100+ tok/s 是智能体实时交互的门槛
3. **工具调用是核心能力**：Tool-Augmented Reasoning 成为标配
4. **本地部署成为卖点**：隐私和成本考量推动本地部署需求
