### 测量 AI 智能体自主性的实践研究

**来源**：Anthropic Research Blog
**核心观点**：通过分析数百万人机交互数据，研究智能体在真实世界中的自主性表现

#### 四大核心发现

**1. Claude Code 自主工作时间显著增长**
- 99.9百分位的回合时长在3个月内几乎翻倍
- 从2025年10月的不到25分钟增长到2026年1月的超过45分钟
- 增长曲线平滑，跨越多个模型版本，说明不仅仅是模型能力提升的结果
- 存在"部署过剩"(deployment overhang)：模型能够处理的自主性超过实际使用中的自主性

**2. 经验用户的行为模式变化**
- 新用户（<50次会话）：约20%使用完全自动批准
- 经验用户（750+次会话）：超过40%使用完全自动批准
- 有趣的是：经验用户中断率也更高（从5%增加到9%）
- 这反映了监督策略的转变：从逐步批准转向"放手运行，必要时介入"

**3. 智能体主动暂停比人类中断更频繁**
- 在最复杂的任务上，Claude Code 主动请求澄清的频率是人类中断的两倍多
- Claude 停止的主要原因：
  - 向用户提供方案选择（35%）
  - 收集诊断信息或测试结果（21%）
  - 澄清模糊或不完整的请求（13%）
  - 请求缺失的凭证或访问权限（12%）
  - 在采取行动前获得批准（11%）
- 人类中断的主要原因：
  - 提供缺失的技术上下文或纠正（32%）
  - Claude 太慢、卡住或过度（17%）
  - 已获得足够帮助可以独立继续（7%）

**4. 智能体在高风险领域的使用**
- 软件工程占 API 工具调用的近50%
- 80%的工具调用来自有某种安全措施的智能体
- 73%有某种形式的人类参与
- 仅0.8%的操作是不可逆的
- 新兴领域：医疗、金融、网络安全

#### 技术要点

**自主性测量方法**
- 定义：智能体是配备工具的 AI 系统，可以执行操作（运行代码、调用外部 API、向其他智能体发送消息）
- 数据源：公共 API（广度）+ Claude Code（深度）
- 指标：回合时长、自动批准率、中断率、风险评分、自主性评分

**风险与自主性评分体系**
- 风险评分 1-10：1=无后果，10=可能造成重大伤害
- 自主性评分 1-10：低=遵循明确人类指令，高=独立运行
- 大多数操作集中在低风险区域，但自主性分布更广

#### 适用场景
- 智能体产品设计：理解用户信任建立过程
- 安全策略制定：设计有效的监督机制
- 能力评估：理解实际部署与理论能力的差距

#### 局限性
- 仅分析 Anthropic 的流量
- 无法完全重建客户的智能体架构
- 部分高风险操作可能是评估/模拟
