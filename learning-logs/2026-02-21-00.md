## 发现内容

### 1. Graph-of-Agents (GoA) 框架
- **来源**: dasroot.net
- **核心观点**: 2026年引入的 GoA 框架使用图模型管理多 LLM 间的通信协作
- **技术要点**:
  - Node Sampling: 基于领域专长选择相关 agent
  - Edge Construction: 基于评估和相关性排序连接 agent
  - Directed/Reverse Message Passing: 精炼响应
  - 在 MMLU-Pro 基准上达到 89.4% 准确率
- **适用场景**: 复杂推理任务、需要多模型协作的场景
- **局限性**: 需要预定义 agent 角色和能力
- **与现有知识关联**: 补充 memory-layers 中的多 agent 协调机制

### 2. 角色化 Agent 设计模式
- **来源**: clickittech.com
- **核心观点**: 角色分离显著提升系统可靠性和可维护性
- **技术要点**:
  - **Planner Agent**: 将高层目标转化为结构化计划
  - **Executor Agent**: 执行具体动作（API调用、代码编写）
  - **Critic Agent**: 对抗性评估，减少错误和幻觉
  - **Verifier Agent**: 确保输出满足预定义约束
- **适用场景**: 企业级 AI 工作流、高风险决策场景
- **关键数据**: 明确角色定义可降低 35% 任务失败率
- **与现有知识关联**: 可应用于晋哥的 AI 辅助编程项目

### 3. AI 外骨骼模型
- **来源**: kasava.dev (HN 381 points)
- **核心观点**: AI 应被视为人类能力的放大器，而非替代者
- **技术要点**:
  - **Micro-Agent Architecture**: 将工作分解为离散任务
  - **Product Graph**: 结合自动化上下文和人类判断
  - **可见的接缝**: 每个组件有清晰的输入输出，便于调试
- **适用场景**: 产品开发、代码分析、客户反馈处理
- **关键洞察**: 
  - 不要问"AI能否做开发者的工作"
  - 要问"开发者一周做的47件事中，哪些可以被放大"
- **与现有知识关联**: 与 haribo-pattern 的 token 优化理念一致

### 4. 通信协议标准化
- **来源**: dasroot.net, clickittech.com
- **核心观点**: 标准化协议是多 agent 系统成功的关键
- **技术要点**:
  - **ACP (Agent Communication Protocol)**: 标准化消息格式
  - **MCP (Model Context Protocol)**: 结构化工具和数据访问，v2.1 增强权限验证
  - **A2A (Agent-to-Agent Protocol)**: 无监督 agent 协作
- **适用场景**: 跨平台 agent 通信、企业级部署
- **关键数据**: Deloitte 2026 框架实现 90% 任务完成率

### 5. 硬件专用化趋势
- **来源**: taalas.com (HN 420 points)
- **核心观点**: AI 推理需要专用硬件才能实现普及
