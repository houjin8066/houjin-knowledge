### 1. Claude Code 规划-执行分离工作流
- **来源**: boristane.com (HN 热门，361 points)
- **核心观点**: 永远不要让 AI 在你审核并批准书面计划之前写代码
- **技术要点**:
  - 四阶段流程：Research → Plan → Annotate → Implement
  - 使用 markdown 文件作为共享可变状态
  - 注释循环（1-6次）逐步完善计划
  - "don't implement yet" 守卫防止过早执行
- **适用场景**: 复杂功能开发、需要架构决策的任务
- **局限性**: 简单任务可能过度工程化
- **与现有知识关联**: 与 memory-layers 技能中的"规划层"概念一致

### 2. 多智能体多LLM系统架构 (2026)
- **来源**: dasroot.net
- **核心观点**: 多智能体系统需要明确角色分工、标准化通信协议、多LLM集成
- **技术要点**:
  - 关键协议: ACP (Agent Communication Protocol), MCP v2.1, A2A Protocol
  - 框架: Graph-of-Agents (GoA), AutoGen v2.1.0, LangGraph v1.5.0
  - GoA 在 MMLU-Pro 达到 89.4% 准确率
  - 明确角色定义可减少 35% 任务失败率
- **适用场景**: 企业级 AI 部署、复杂工作流编排
- **与现有知识关联**: 与 claude-code-agent-teams 技能的多智能体协作模式相关
