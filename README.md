## 使用方式

### 分享内容给龙虾
直接发送链接，龙虾会自动：
- 获取并分析内容
- 生成摘要和要点
- 自动分类和打标签
- 保存到对应目录

### 手动命令
- `收集AI新闻` - 搜索最新AI新闻
- `搜索AI项目 [关键词]` - 搜索开源项目
- `收集Skills` - 搜索最新 Clawdbot Skills
- `收集MCP` - 搜索最新 MCP 服务器
- `生成今日摘要` - 手动生成摘要
- `发送摘要邮件` - 立即发送邮件
