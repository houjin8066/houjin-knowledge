## 核心观点

**卖情绪价值比卖功能更赚钱**

```
产品价值 = 功能价值 + 情绪价值
```

---

## 三个赚钱赛道

### 1️⃣ 修补工具 KnitPatch（卖疗愈）

| 维度 | 内容 |
|------|------|
| **产品** | 织物修补贴片 KnitPatch |
| **切入点** | 环保修复、旧物新生 |
| **情绪价值** | 疗愈感 —— 修复破损衣物的满足感 |
| **目标人群** | 环保主义者、手工爱好者、节俭人群 |
| **核心卖点** | 不是卖产品，是卖"修复的仪式感" |

**为什么能赚钱：**
- 环保趋势上升，"可持续消费"成为身份标签
- 修复过程本身有治愈效果
- 客单价不高但复购率高

---

### 2️⃣ 3D动漫水晶（卖人设）

| 维度 | 内容 |
|------|------|
| **产品** | 3D水晶摆件（定制动漫/人物形象） |
| **切入点** | 桌面美学、情绪价值 |
| **情绪价值** | 人设表达 —— "这就是我" |
| **目标人群** | 二次元、追星族、个性表达者 |
| **核心卖点** | 自带流量（IP粉丝主动搜索） |

**为什么能赚钱：**
- 粉丝经济，用户为喜欢的角色/偶像付费意愿强
- 定制化产品溢价空间大
- 社交属性强，容易形成传播

**注意事项：**
- IP版权问题需要关注（评论区有人问"不侵权么？"）

---

### 3️⃣ 清洁胶/清洁产品（卖焦虑）

| 维度 | 内容 |
|------|------|
| **产品** | 键盘清洁胶、缝隙清洁工具 |
| **切入点** | 治愈强迫症、焦虑经济 |
| **情绪价值** | 掌控感 —— 把脏东西清理干净的爽感 |
| **目标人群** | 强迫症、洁癖、追求秩序感的人 |
| **核心卖点** | 视频展示效果极佳（清洁前后对比） |

**为什么能赚钱：**
- 焦虑经济是长期趋势
- 产品效果可视化，适合短视频营销
- 低成本高毛利
