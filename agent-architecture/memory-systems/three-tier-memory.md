## 概述

一个跨分布式智能体团队扩展的3层记忆系统架构。

## 架构

```
┌─────────────────────────────────────────────────────────┐
│                    Core Memory                           │
│                   核心记忆                               │
│              即时决策的活跃上下文                         │
│                                                         │
│  • 当前任务上下文                                        │
│  • 活跃对话状态                                          │
│  • 即时工作记忆                                          │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│                   Recall Memory                          │
│                   回忆记忆                               │
│              带加权检索的情景经验                         │
│                                                         │
│  • 情景记忆（发生了什么）                                │
│  • 加权检索（新近度 + 相关性评分）                       │
│  • 溢出处理（自动上下文摘要）                            │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│                  Archival Memory                         │
│                   档案记忆                               │
│              带语义索引的长期知识                         │
│                                                         │
│  • 长期知识存储                                          │
│  • 语义索引和检索                                        │
│  • 跨智能体记忆桥接                                      │
└─────────────────────────────────────────────────────────┘
```

## 关键洞察

### 个体记忆 + 共享上下文池
智能体需要两者：
- **个体记忆**：自己的经验和学习
- **共享上下文池**：团队协调所需的共享状态

### 心跳协议
- 每30秒同步关键状态
- 保持智能体间的状态一致性
- 防止状态漂移

### 效果数据
- 共享情景记忆 vs 隔离操作
- **40%** 更好的任务完成率

## 技术细节

### Stanford启发的加权检索
```
score = α × recency + β × relevance

recency: 时间衰减函数
relevance: 语义相似度
α, β: 可调权重
```

### 溢出处理
- 当上下文超出限制时
- 自动生成摘要
- 保留关键信息，压缩细节

### 跨智能体记忆桥接
- 用于委托工作流
- 智能体A可以访问智能体B的相关记忆
- 通过权限控制访问范围

## 与 Clawdbot 的映射

| 三层记忆 | Clawdbot 对应 |
|---------|--------------|
| Core Memory | 当前会话上下文 |
| Recall Memory | memory/YYYY-MM-DD.md |
| Archival Memory | MEMORY.md + knowledge/ |

## 改进建议

1. **加权检索**：memory_search 可以加入新近度权重
2. **心跳同步**：HEARTBEAT.md 可以包含状态同步逻辑
3. **跨智能体桥接**：sub-agent 可以访问主 session 的部分记忆
