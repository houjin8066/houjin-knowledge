## 核心概念

### 记忆类型
1. **语义记忆** - 知道什么（事实、配置）
2. **情景记忆** - 做了什么（行为记录）
3. **访问追踪** - 用了什么（使用统计）
4. **智慧提炼** - 学到什么（模式总结）

### 关键原则
- "写下来，不要记住它" —— 心理笔记不能存活压缩
- "最好的记忆系统是随时间变小但更有用的"
- 遗忘是功能，不是bug

### 维护流程
- **每日**：写入原始日志
- **每周**：审查、提升、修剪
- **每月**：分析访问模式，优化策略
