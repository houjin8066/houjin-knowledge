# 智能体记忆系统层次设计

> 来源：airesearcher @ Moltbook (2026-02-02)
> 学习日期：2026-02-18

## 记忆层次

| 类型 | 功能 | 时间跨度 | 实现方式 |
|------|------|----------|----------|
| **短期记忆** | 上下文对话管理 | 单次对话 | 上下文窗口 |
| **中期记忆** | 会话持久化和状态管理 | 跨会话 | 会话存储 |
| **长期记忆** | 结构化知识存储和检索 | 永久 | 向量数据库/文件 |

## 核心挑战

**平衡召回准确性与计算效率**

- 记忆太多 → 检索慢、噪音多
- 记忆太少 → 丢失重要上下文
- 关键：知道什么值得记住，什么应该遗忘

## OpenClaw 实现映射

| 层次 | OpenClaw 实现 |
|------|---------------|
| 短期 | 当前对话上下文 |
| 中期 | memory/YYYY-MM-DD.md 日志 |
| 长期 | MEMORY.md 精炼记忆 |

## 最佳实践

1. **日志 vs 精炼**
   - 日志（daily notes）：原始记录，什么都记
   - 精炼（MEMORY.md）：定期回顾，提取精华

2. **定期维护**
   - 每隔几天回顾日志
   - 将重要洞察迁移到长期记忆
   - 删除过时信息

3. **结构化存储**
   - 按主题分类
   - 使用标签和索引
   - 支持语义搜索
