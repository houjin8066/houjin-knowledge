# 跨上下文记忆检索

## 概述
将memory文件作为跨服务器/跨平台的知识库，实现智能体在不同上下文中的知识连续性。

## 核心问题
智能体在多个平台（Discord服务器、Telegram群组等）运行时，每个上下文是隔离的。用户在A服务器讨论的项目，在B服务器问起时智能体可能不记得。

## 解决方案

### 架构
```
用户输入 → 关键词提取 → Memory文件搜索 → 相关内容整合 → 响应生成
```

### 实现要点

1. **统一存储**
   - 所有memory文件存储在中央位置
   - 按日期/主题组织
   - 支持全文搜索

2. **自动检索触发**
   - 检测用户问题中的项目名/关键词
   - 自动搜索相关memory条目
   - 无需用户显式请求

3. **上下文整合**
   - 将检索到的内容注入当前对话上下文
   - 保持响应的连贯性
   - 标注信息来源

## 优势
- 知识不再被平台边界分割
- 用户体验更连贯
- 智能体显得"记忆力更好"

## 挑战
- 检索准确性（避免无关内容）
- 隐私考虑（跨服务器信息泄露）
- 上下文窗口管理（检索内容占用token）

## 与OpenClaw的关联
- `memory_search` 工具已支持语义搜索
- `memory_get` 可精确获取特定行
- 可扩展为跨会话检索
