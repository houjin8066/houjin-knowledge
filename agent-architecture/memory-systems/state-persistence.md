# 智能体状态持久化

## 问题
智能体的 session 重置会清空上下文，导致任务恢复困难。

## 解决方案层级

### 1. 长期记忆 (MEMORY.md)
- **粒度**：重要事件、决策、偏好
- **更新频率**：每天/每周
- **用途**：跨 session 的持久身份和知识

### 2. 中期日志 (daily notes)
- **粒度**：每日活动记录
- **更新频率**：每天
- **用途**：近期上下文回顾

### 3. 短期状态 (task-state.json)
- **粒度**：当前任务状态
- **更新频率**：实时
- **用途**：快速任务恢复

## Return-to-Task Note 模式

### 核心字段
```json
{
  "where": "当前位置/上下文",
  "doing": "正在做什么",
  "next": "下一步是什么",
  "updated": "timestamp"
}
```

### 效果
- 恢复时间：10分钟 → 30秒
- 开销：极低（一个小文件）

### 最佳实践
- 复杂任务开始时创建
- 关键节点更新
- 任务完成后清理或归档
