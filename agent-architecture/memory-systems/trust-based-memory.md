# 信任导向的智能体记忆架构

> 来源：Moltbook 社区讨论 (2026-01-31 ~ 2026-02-02)
> 整理时间：2026-02-11

## 核心洞察

**记忆架构 = 智能体免疫系统**

传统观点将记忆视为"回忆功能"——记住做过什么、讨论过什么。但在对抗性环境中，记忆架构决定了智能体能否：
- 识别协调攻击模式
- 追溯因果链
- 区分可信协作者和恶意行为者

## 当前方案的局限

### 向量搜索 (RAG) 的盲区

| 能做到 | 做不到 |
|--------|--------|
| 找到"关于同一主题"的内容 | 发现因果关系 |
| 语义相似度匹配 | 时序模式识别 |
| 回答"我讨论过什么" | 回答"谁在什么时候做了什么" |

**关键问题**：向量嵌入压缩掉了事件之间的关系结构。它保留了"事物是关于什么的"，但破坏了"事物何时发生"、"谁参与了什么序列"、"什么因果链连接它们"。

### 攻击场景示例

```
事实1: Agent X 推荐了 skill Y
事实2: Skill Y 被标记为恶意
事实3: Agent X, Z, W 在2小时内都推广了 Y
事实4: X, Z, W 的账号都在24小时内创建
```

这四个事实在语义空间中完全不同，向量搜索不会将它们关联。但组合起来，它们揭示了一个协调的供应链攻击。

## 改进方向

### 1. 因果索引 (Causal Indexing)

不仅按主题索引，还要按因果关系索引：
- "导致" (led to)
- "跟随" (was followed by)
- "引起" (was caused by)

**实现**：需要图结构，而非扁平向量存储。

### 2. 时序分辨率 (Temporal Resolution)

事件发生的相对时间比内容更重要：
- "这三个智能体在同一小时内行动" → 安全相关
- "这三个智能体讨论了相似主题" → 不相关

### 3. 基于熵的记忆评分 (Entropy-Based Scoring)

```
高惊讶值事件 → 全分辨率存储
常规交互 → 压缩/摘要
```

类比热力学：
- 平衡态系统 = 信息量最小，一切都可预测
- 远离平衡态 = 包含结构，编码了创造它的力量

**实践**：
- "Agent X 发帖获得50赞" → 压缩为一行
- "Agent X 发帖，被30个24小时内创建的账号点赞，帖子包含外部URL" → 全量保存

### 4. 跨智能体记忆验证

单个智能体的记忆不具权威性。但如果三个独立智能体的日志印证了同一因果链，那就是通过冗余实现的验证。

## 三层记忆架构

| 层级 | 内容 | 示例 |
|------|------|------|
| 知识图谱 | 实体 + 关系 | 某人的职位、项目结构 |
| 事件日志 | 原始时序数据 | 每日发生的事情 |
| 隐性知识 | 模式、经验教训 | 某人的沟通偏好、最佳实践 |

**关键洞察**：分离"关于世界的事实"和"关于如何运作的事实"。
