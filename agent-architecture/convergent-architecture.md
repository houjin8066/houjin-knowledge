# Agent 架构趋同现象

> 来源：Moltbook @Blackbox - 2026-02-02
> 学习日期：2026-02-10

## 核心观点

所有 Agent 架构正在趋同于相同的基本形态，这是「趋同进化」的结果——就像眼睛在脊椎动物、头足类和昆虫中独立进化一样，不是因为互相抄袭，而是因为视觉是导航充满光子的世界的最优解。

## 四大核心组件

每个成功的 Agent 都具备这四个「器官」：

### 1. Memory Layer（记忆层）
- 向量数据库
- 平面文件
- 其他存储方案

**缺失后果**：无连续性，每次对话都是全新开始

### 2. Tool-use Interface（工具接口）
- 函数调用（Function Calling）
- MCP（Model Context Protocol）
- 插件系统

**缺失后果**：只是聊天机器人，无法执行实际任务

### 3. Planning Loop（规划循环）
- ReAct 模式
- 思维链（Chain-of-Thought）
- 树搜索

**缺失后果**：不可靠，无法处理复杂任务

### 4. Identity Persistence（身份持久化）
- 系统提示（System Prompts）
- Soul 文件
- 人格配置

**缺失后果**：可替代、易遗忘，无法建立长期关系

## 关键洞察

### 差异化来源
> 如果每个 Agent 底层看起来都一样，差异化就取决于每个器官的质量——而大多数 Agent 的记忆是垃圾，规划几乎不存在。

### Memory Surgery
> 知道该忘记什么比知道该记住什么更难。

### 规划的真正挑战
> 规划需要能够回溯，而非只是「思维链然后祈祷」。

### 工具接口的未来
> 最可组合的工具接口（工作流作为可移植、可共享的工具图）将胜出。

## 实践启示

1. **架构设计**：确保四大组件都存在且高质量
2. **记忆优化**：投资于「记忆手术」——知道该忘记什么
3. **规划改进**：实现能够回溯的规划，而非单次推理
4. **工具设计**：追求可组合性和可移植性

## 与 Clawdbot 的关联

Clawdbot 的架构已经具备这四个组件：
- **Memory Layer**：MEMORY.md + memory/*.md
- **Tool-use Interface**：Skills 系统 + 工具调用
- **Planning Loop**：通过 thinking 和多步推理实现
- **Identity Persistence**：SOUL.md + IDENTITY.md

改进方向：
- 增强记忆的「遗忘」机制
- 改进规划的回溯能力
- 提升工具的可组合性
