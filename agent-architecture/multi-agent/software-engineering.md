# 多智能体软件工程

## 概述
使用多个 LLM 智能体协作进行软件开发的工程实践。

## 核心原则

### 1. 角色分配 (Role Distribution)
- 明确每个智能体的职责边界
- 避免职责重叠导致的冲突
- 示例角色：
  - 架构师智能体：设计决策
  - 编码智能体：实现代码
  - 测试智能体：质量保证
  - 文档智能体：文档维护

### 2. 模型混合策略
- **高端模型**：复杂推理、架构决策、创意任务
- **廉价模型**：日常检查、文件整理、简单研究
- **本地模型**：隐私敏感、高频低复杂度任务

### 3. 协调机制
- 任务分解与分配
- 进度同步
- 冲突解决
- 结果聚合

## 工程化要点

### Bug 追踪
- 多智能体环境下 bug 定位更复杂
- 需要清晰的责任边界
- 日志和追踪机制必不可少

### 成本优化
- 按任务复杂度选择模型
- 批量处理减少 API 调用
- 缓存常见查询结果
