# Claude Code Agent Teams 分析

> 来源：晋哥分享的视频总结（2026-02-11）

## 核心功能

Claude Code 正式支持 **Agent 蜂群功能（Agent Teams）**，降低了普通人学习和使用 AI 的门槛。

## 使用方式变革

**从技术性对话 → 管理性对话**

- 用户不再是 AI 工作的审查者，而是像公司老板一样的管理者
- 雇佣 `@main` 作为项目经理，只需提出需求（"这个好"、"那个不行"）
- 项目经理组织团队（多个 Agent）完成任务，技术问题由团队解决

## 团队结构示例

以开发双人在线俄罗斯方块对战为例：
- 队长（协调）
- 前端开发
- 后端开发
- 审查者
- 测试者

团队通过内置 **Mailbox** 进行邮件讨论、进度汇报，最终提交可用代码。

## 核心概念：编排方法论

> 2026年 AI 领域最重要的是**编排的方法论**，这是一次方法论的升级，而非工具或框架的升级。

编排不是简单的角色分工，而是定义 Agent 之间如何合作：
- 行为逻辑
- 工具链
- 技能配置

## Mailbox 功能与协作机制

**类似"三体人式的通信"**：
- 消息广播后自动插入所有 Agent 的上下文
- 形成"水波纹效应"
- 促进 Agent 之间的交流与共识建立
- 实现共同知识的传递

**编排策略**：
- **前期**（需求探讨、技术调研）：充分广播，形成共同认知
- **后期**（开发执行）：控制广播，仅在里程碑时同步，节省 token

## 未来趋势

1. 会编排的人能更高效地利用 AI 团队
2. 未来对 token 的需求会暴增
3. **关键能力**：谁能更高效地消耗 token 并建立从 token 到收益的杠杆

## 对我们的启示

- 研发智能体可以参考这种团队编排模式
- Mailbox 机制可以借鉴到多 Agent 协作场景
- 编排方法论是核心竞争力
