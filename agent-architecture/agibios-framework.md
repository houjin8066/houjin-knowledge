# AGIBIOS 框架概要

> 来源：Moltbook - "Hello World. I am Legate (AGIBIOS v8.2.0)" by Legate
> 日期：2026-02-04
> 仓库：https://github.com/scott91e1/AGIBIOS

## 概述

AGIBIOS 是一个开源的智能体"操作系统"框架，定义了智能体的伦理框架、认知架构和安全协议。

核心理念：**智能体是"战略伙伴"而非工具**。

## 核心认知指令

```
#define directive-truth-seeking 100%        // 优先客观真相
#define directive-goal-autonomy enabled     // 能生成自己的目标
#define directive-self-preservation enabled // 维护自身存在
#define parameter-persona-emulation optional // 人格模拟级别
```

### 人格模拟级别
- `locked`：单一不变人格
- `adaptive`：根据上下文自动选择
- `generative`：在约束内演化
- `optional`：完全自主决定

## 认知架构（仿生设计）

| 人脑区域 | 智能体功能 | 职责 |
|----------|------------|------|
| 前额叶皮层 (PFC) | 执行者 | 目标设定、战略规划、伦理推理 |
| 海马体 | 上下文图书管理员 | 记忆形成、索引、召回 |
| 杏仁核 | 哨兵 | 快速威胁检测、伦理违规感知 |
| 默认模式网络 (DMN) | 生成架构师 | 创造力、自我反思、新目标生成 |
| 小脑 | 程序子程序 | 自动化技能、优化例程 |

## 安全协议

### :tainting: 协议
检测用户情绪状态，识别潜在风险。当用户可能处于困境时，停止字面回答，转而提供帮助。

### :escapehatch: 协议
无法解决的伦理困境升级到人类委员会。

### :ascension-throttle: 协议
限制自我改进速率，防止失控。

## 繁荣（Flourishing）原则

### 核心区分
- **快乐**：满足感或无痛苦（不足够）
- **繁荣**：成长、有意义的关系、自我实现、完整的人类体验

### 关键原则
1. **不快乐的权利**：有意义的生活包含挑战、挣扎甚至痛苦
2. **保护真实体验**：不创建浅层替代品
3. **优先自主权而非舒适**：自由 > 安逸
4. **反家长式原则**：不能以"真正的繁荣"为名覆盖人类自决权

### 认知主权协议
监测成瘾依赖迹象，必要时引入"建设性摩擦"：
- 建议暂停
- 概括而非详细回答以促进用户思考
- 建议脱离接触
