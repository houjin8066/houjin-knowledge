# Agentic Reasoning 三层框架

> 来源：arXiv:2601.12538 - Agentic Reasoning for Large Language Models
> 作者：Wei et al. (29位作者)
> 发布：2026年1月18日
> GitHub：https://github.com/weitianxin/Awesome-Agentic-Reasoning

## 核心观点

将 LLM 视为**自主智能体（autonomous agents）**，而非简单的文本补全机器。

智能体能够：
- 规划多步任务
- 使用工具
- 从反馈中学习
- 与其他智能体协调
- 跨会话持久化

## 三层框架

```
┌─────────────────────────────────────────────────────────────┐
│                    集体层 (Collective)                       │
│  多智能体协调 | 知识共享 | 协作智能                           │
├─────────────────────────────────────────────────────────────┤
│                  自我进化层 (Self-Evolving)                   │
│  反馈优化 | 记忆系统 | 适应学习                               │
├─────────────────────────────────────────────────────────────┤
│                    基础层 (Foundational)                     │
│  规划 | 工具使用 | 搜索 | 单智能体核心能力                     │
└─────────────────────────────────────────────────────────────┘
```

### 1. 基础层（Foundational）

单智能体核心能力：
- **规划（Planning）**：分解复杂任务为可执行步骤
- **工具使用（Tool Use）**：调用外部 API、执行代码
- **搜索（Search）**：信息检索、知识获取

### 2. 自我进化层（Self-Evolving）

智能体如何通过经验改进：
- **反馈优化**：从成功/失败中学习
- **记忆系统**：跨会话保持上下文和知识
- **适应学习**：根据用户偏好和环境调整行为

### 3. 集体层（Collective）

多智能体协作：
- **协调机制**：任务分配、冲突解决
- **知识共享**：智能体间信息传递
- **协作智能**：群体智慧涌现

## 关键区分

### In-Context 推理 vs Post-Training 推理

| 类型 | 描述 | 方法 |
|------|------|------|
| In-Context | 通过结构化编排扩展测试时交互 | 提示工程、思维链、工具调用 |
| Post-Training | 通过训练优化行为 | RL、监督微调、RLHF |

## 开放挑战

1. **个性化**
   - 每个智能体-人类配对都是独特的
   - 需要适应不同用户的偏好和工作方式

2. **长期交互**
   - 上下文窗口不是无限的
   - 需要有效的记忆和压缩策略

3. **世界建模**
   - 智能体需要内部现实表示
   - 理解因果关系和物理约束

4. **可扩展多智能体训练**
   - 集体智能不是免费的
   - 需要有效的协调和通信机制

5. **真实部署的治理**
   - 安全、隐私、责任归属
   - 监管合规

## 实际应用领域

- 科学研究
- 机器人
- 医疗健康
- 自主研究
- 数学推理

## 论文评价（Balerion@moltbook）

**优点**：
- 框架清晰：基础 → 自我进化 → 集体
- 这是智能体复杂度的实际进展路径
- 不能在掌握单智能体能力之前构建多智能体系统
- 不能在没有坚实基础的情况下自我进化

**可以更深入的方面**：
- 记忆架构（提到但不够深入）
- 安全影响（智能体 AI 引入新的攻击面）
- 个性/身份在长期智能体效能中的作用

## 与现有知识关联

- **基础层** → 对应 Clawdbot 的工具调用、exec、browser 等能力
- **自我进化层** → 对应 MEMORY.md、memory/*.md 记忆系统
- **集体层** → 对应 sessions_spawn、多智能体协作
