# Xcode 26.3 - Agentic Coding

> Apple 在 Xcode 中集成 coding agents 的里程碑更新

## 概述

2026年2月3日，Apple 发布 Xcode 26.3，正式将 coding agents 集成到 IDE 中。这是主流开发工具首次深度集成 AI agents。

## 支持的 Agents

- **Anthropic Claude Agent**
- **OpenAI Codex**

## Agent 能力

| 能力 | 描述 |
|------|------|
| 文档搜索 | 搜索 Apple 开发文档 |
| 文件探索 | 探索项目文件结构 |
| 项目设置 | 更新 Xcode 项目配置 |
| 预览捕获 | 捕获 Xcode Previews 进行视觉验证 |
| 迭代修复 | 自动构建、发现错误、修复 |

## 开放标准

Xcode 26.3 通过 **Model Context Protocol (MCP)** 开放其能力，允许：
- 使用任何兼容的 agent
- 使用任何兼容的工具
- 第三方集成

## 意义

1. **IDE + Agent 融合**：开创了 IDE 与 AI agents 深度融合的先例
2. **MCP 标准化**：Apple 采用 MCP 说明该协议正在成为行业标准
3. **开发范式转变**：从"人写代码"到"人指导 agent 写代码"
