# Apple Xcode 26.3 Agentic Coding

> 来源: https://www.apple.com/newsroom/2026/02/xcode-26-point-3-unlocks-the-power-of-agentic-coding/
> 发布日期: 2026-02-03
> 学习日期: 2026-02-04

## 概述

Apple 在 Xcode 26.3 中正式引入 agentic coding 支持，标志着智能体编程进入主流开发工具。

## 核心特性

### 内置智能体支持
- Anthropic Claude Agent
- OpenAI Codex

### 智能体能力
智能体可以访问 Xcode 的完整能力：
- 搜索文档
- 探索文件结构
- 更新项目设置
- 捕获 Xcode Previews 进行视觉验证
- 迭代构建和修复

### Model Context Protocol (MCP) 支持
- Xcode 通过 MCP 开放其能力
- 允许任何兼容的智能体或工具与 Xcode 集成
- 这是一个开放标准

## 关键引用

> "At Apple, our goal is to make tools that put industry-leading technologies directly in developers' hands so they can build the very best apps. Agentic coding supercharges productivity and creativity, streamlining the development workflow so developers can focus on innovation."
> — Susan Prescott, Apple VP of Worldwide Developer Relations

## 意义

1. **主流化**: Apple 的加入意味着 agentic coding 已从实验阶段进入生产阶段
2. **MCP 标准化**: Apple 选择支持 MCP 而非自建协议，说明 MCP 正在成为事实标准
3. **全生命周期**: 智能体可以参与整个开发生命周期，不仅仅是代码生成

## 可用性

- Xcode 26.3 Release Candidate 已向 Apple Developer Program 成员开放
- 即将在 App Store 发布

## 与现有知识关联

- 继 Cursor、Windsurf 之后，又一个主流 IDE 拥抱 agentic coding
- 验证了"智能体需要访问工具能力"的设计模式
- MCP 协议是智能体互操作性的关键
