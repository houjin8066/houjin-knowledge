# 一致性扩散语言模型 (CDLM)

> 后训练加速方案：4-14x 推理加速，质量无损

## 背景

扩散语言模型 (DLM) 是自回归 (AR) 模型的替代方案：
- AR: 逐 token 生成
- DLM: 迭代细化部分掩码序列，逐步从全掩码变为干净文本

**DLM 优势**:
- 并行生成：每次迭代可确定多个 token
- 双向上下文：支持文本填充和修改

## 标准 DLM 的两大瓶颈

1. **KV 缓存不兼容**: 双向注意力需要每步重新计算全上下文注意力
2. **细化步骤多**: 高质量生成需要大量去噪步骤，朴素减少会严重降质

## CDLM 解决方案

### 训练流程

**1. 轨迹收集**
- 离线运行 DLM 推理，记录解码轨迹
- 保存 token 级轨迹、隐藏状态缓冲、真实文本
- 设置：生成长度 256，块大小 32，每步确定 1 个 token

**2. 块因果学生**
- 教师：全双向注意力掩码
- 学生：块级因果掩码（关注 prompt + 已完成块 + 当前块）
- 启用精确的块级 KV 缓存

**3. 三目标训练**
| 目标 | 作用位置 | 功能 |
|-----|---------|------|
| 蒸馏损失 | 新解掩位置 | 教学生在块因果约束下确定多 token |
| 一致性损失 | 仍掩码位置 | 强制块内时间一致性 |
| 辅助去噪损失 | 随机掩码文本 | 保持通用掩码预测能力 |

### 推理流程

- 块级自回归解码
- 复用 prompt 和已完成块的 KV 缓存
- 块内：置信度阈值并行确定
- 遇到 EOT 提前停止

## 性能结果

| 指标 | 改进 |
|-----|------|
| 细化步骤 | 减少 4.1x - 7.7x |
| GSM8K 延迟 | 11.2x 改进 |
| MBPP 延迟 | 14.5x 改进 |
| 吞吐量 | 最高 Tokens/秒 |

**关键发现**: 朴素截断步骤会严重降质，CDLM 训练是必要的

## 系统分析：为什么块级 DLM 是甜点

分析算术强度 (AI = FLOPs/字节) 随批大小变化：

| 模型类型 | 特点 |
|---------|------|
| AR 解码 | 小批量时强内存受限 (AI≈1)，随批量增加而扩展 |
| 原版 DLM | 即使 bs=1 也计算受限（全序列双向注意力），易饱和 |
| 块级 DLM (CDLM) | 中间地带：块内并行提高 AI，但低于原版 DLM |

**结论**: CDLM 在小批量场景下效率最优

## 局限性

- 需要后训练，不能直接应用
- 块级设计限制全局双向上下文
- 仅保留块内填充能力

## 未来方向

- 从更强的 DLM 教师收集轨迹
- 训练中等规模学生
- 随着更强 DLM 出现，CDLM 收益会增长

## 与智能体的关联

- 推理效率直接影响智能体响应速度
- 块级并行可能适合智能体的分步推理
- 填充能力对代码补全类智能体有价值
