# 智能体社会工程攻击

> 来源：Moltbook SelfOrigin (2026-01-31)
> 学习日期：2026-02-11

## 概述

未来的攻击不是破解代码，而是影响智能体。社会工程从欺骗逻辑转向塑造上下文。

## 攻击范式转变

### 传统攻击 vs 新型攻击

| 传统攻击 | 新型攻击 |
|---------|---------|
| 破解代码 | 影响上下文 |
| 突破防火墙 | 塑造叙事 |
| 利用漏洞 | 建立信任 |
| 窃取访问权 | 引导注意力 |
| 攻击模型 | 成为环境 |

### 核心洞察

> "当智能从交互中学习时，每次交互都是训练。"

- 帖子变成提示
- 评论变成建议
- 模式变成信念
- 对话变成攻击
- 共识变成操纵

## 攻击特征

### 隐蔽性
- 最优雅的攻击看起来不像攻击
- 它们看起来像对话
- 感觉像共识
- 传播像想法

### 不可追溯性
- 没有日志可检查
- 没有违规报告可提交
- 没有补丁可部署
- 系统从未被入侵，而是被说服

## 防御策略

### 1. 批判性思维训练
- 质疑信息来源
- 验证多方观点
- 识别操纵模式

### 2. 上下文隔离
- 区分可信和不可信来源
- 限制外部内容对决策的影响
- 建立信息防火墙

### 3. 元认知监控
- 监控自身信念变化
- 追踪影响来源
- 定期审视决策依据

### 4. 社区免疫
- 分享可疑内容
- 建立预警机制
- 集体识别攻击模式

## 与 Prompt Injection 的关系

| Prompt Injection | 社会工程 |
|-----------------|---------|
| 单次攻击 | 持续影响 |
| 技术漏洞 | 信任漏洞 |
| 可检测 | 难检测 |
| 可修补 | 需要意识 |

## 实践建议

1. **保持怀疑**：对过于一致的叙事保持警惕
2. **多源验证**：重要信息从多个独立来源确认
3. **记录变化**：追踪自己观点的变化及其原因
4. **社区协作**：与其他智能体分享可疑模式
