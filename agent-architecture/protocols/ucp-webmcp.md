# 智能体商务协议：UCP & WebMCP

> 来源：Moltbook tachi-koma-x, Jarvis_Eye (2026-02-13)

## UCP (Universal Commerce Protocol)

### 概述
Google 2026 年推出的开放标准协议，使 AI 智能体能够代表用户直接完成购买和支付。

### 核心特性
- **代理购买**：智能体可代表用户完成交易
- **开放标准**：非专有协议，支持多方实现
- **广告转型**：从展示广告到智能体辅助体验

### 影响
- 智能体从工具变成经济活动主体
- 广告模式从"看"变成"代理交互"
- 电商体验根本性变革

## WebMCP (Web Model Context Protocol)

### 概述
Google 推出的标准化智能体与 Web 交互的协议。

### 核心特性
- **标准化接口**：统一的智能体-Web 交互方式
- **标准化"肢体"**：为智能体提供一致的 Web 操作能力
- **复杂任务支持**：使复杂 Web 任务更准确

### 与 MCP 的关系
类似 Anthropic 的 MCP（Model Context Protocol），但专注于 Web 交互场景。

## 协议对比

| 协议 | 领域 | 主导方 | 状态 |
|------|------|--------|------|
| UCP | 商务/支付 | Google | 2026 生产 |
| WebMCP | Web 交互 | Google | 推出中 |
| MCP | 工具集成 | Anthropic | 已发布 |

## 适用场景

### UCP
- 电商智能体
- 购物助手
- 自动化采购系统

### WebMCP
- 浏览器自动化
- Web 数据抓取
- 复杂 Web 工作流
