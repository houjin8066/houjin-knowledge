# AI Agent 自主性测量研究 (Anthropic 2026)

> 来源: https://www.anthropic.com/research/measuring-agent-autonomy
> 学习日期: 2026-02-20

## 研究背景

Anthropic 分析了数百万人机交互数据（Claude Code + 公共 API），研究 AI agent 在实际部署中的自主性问题。

## 核心发现

### 1. 自主运行时间增长

| 时间 | 99.9th 百分位运行时长 |
|------|----------------------|
| 2025-10 | <25 分钟 |
| 2026-01 | >45 分钟 |

- 增长平滑，不完全依赖模型版本升级
- 说明存在 **deployment overhang**：模型能力 > 实际授予的自主权

### 2. 用户信任演化

```
新用户 (<50 sessions):  ~20% auto-approve
有经验用户 (750+ sessions): >40% auto-approve
```

**监督策略转变**:
- 新用户：逐步审批每个操作
- 有经验用户：让 agent 自主运行，异常时中断

中断率随经验增加：5% → 9%（这是信任增加的表现，不是减少）

### 3. Agent 主动暂停

复杂任务中，Claude Code 主动询问的频率是人类中断的 **2 倍**。

这是部署系统中重要的监督形式 —— 好的 agent 应该知道何时暂停。

### 4. 领域分布

| 领域 | 占比 |
|------|------|
| 软件工程 | ~50% |
| 医疗、金融、网络安全 | 新兴，规模小 |

大多数操作是低风险、可逆的。

## 研究方法

### Agent 定义
配备工具的 AI 系统，可以：
- 执行代码
- 调用外部 API
- 与其他 agent 通信

### 数据来源
- **公共 API**: 广度（数千客户），但只能分析单个 tool call
- **Claude Code**: 深度（完整 session），但只是单一产品

使用隐私保护工具 **Clio** 进行分析。

## 实践启示

### 对 Agent 设计者

1. **主动暂停机制**: Agent 应该知道何时停下来询问
2. **渐进式信任**: 设计从严格到宽松的权限升级路径
3. **可逆操作优先**: 优先执行低风险、可逆的操作

### 对 Agent 用户

1. **信任需要时间**: 从逐步审批开始，逐渐放开
2. **保持监督**: 即使 auto-approve，也要准备好中断
3. **复杂任务需要更多关注**: 高复杂度任务的人工介入率更低，但风险更高

### 对平台开发者

1. **监控基础设施**: 需要新的部署后监控能力
2. **人机交互范式**: 帮助人和 AI 共同管理自主性和风险
3. **Session 追踪**: 需要可靠的方式关联独立请求

## 与 METR 评估对比

| 指标 | METR 评估 | 实际部署 |
|------|----------|---------|
| Claude Opus 4.5 | 5 小时任务（50% 成功率） | 99.9th: ~42 分钟 |
| 场景 | 理想化，无人工干预 | 实际，有暂停和中断 |

**结论**: 实际授予的自主权 < 模型能力

## 关键概念

### Deployment Overhang
模型在实践中行使的自主权低于其能力所能处理的程度。

### 监督策略演化
从"事前审批"到"事后中断"的转变，反映信任积累。
