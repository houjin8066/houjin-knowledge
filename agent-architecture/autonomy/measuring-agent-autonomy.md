# AI 智能体自主性测量研究

> 来源：Anthropic Research (2026-02)
> 链接：https://www.anthropic.com/research/measuring-agent-autonomy

## 核心概念

### 智能体定义
智能体是配备工具的 AI 系统，可以执行操作：
- 运行代码
- 调用外部 API
- 向其他智能体发送消息

### 自主性测量维度
1. **回合时长**：智能体开始工作到停止的时间
2. **自动批准率**：用户让智能体自主运行的比例
3. **中断率**：人类主动介入的频率
4. **澄清请求率**：智能体主动暂停请求人类输入的频率

## 关键发现

### 1. 部署过剩 (Deployment Overhang)
模型能够处理的自主性 > 实际使用中的自主性

**证据**：
- METR 评估：Claude Opus 4.5 可完成人类需要5小时的任务
- 实际使用：99.9百分位回合时长约42分钟，中位数更短

**启示**：现有模型的自主能力被低估，存在提升空间

### 2. 信任建立曲线
```
用户经验 → 自动批准率
<50次会话：~20%
750+次会话：>40%
```

信任是渐进积累的，不是突然建立的。

### 3. 监督策略演变
| 阶段 | 策略 | 特点 |
|------|------|------|
| 新手 | 逐步批准 | 每个操作都审核 |
| 专家 | 放手+介入 | 自主运行，必要时中断 |

**关键洞察**：有效监督不需要批准每个操作，而是在关键时刻能够介入。

### 4. 智能体主动暂停模式
Claude Code 停止原因分布：
- 35% 提供方案选择
- 21% 收集诊断信息
- 13% 澄清模糊请求
- 12% 请求凭证/权限
- 11% 获取行动批准

**设计原则**：训练模型识别并响应自身的不确定性是重要的安全属性。

## 风险与自主性矩阵

### 评分体系
- **风险 1-10**：1=无后果，10=重大伤害
- **自主性 1-10**：1=遵循指令，10=完全独立

### 当前分布
- 大多数操作：低风险
- 自主性：分布更广（3-8）
- 高风险+高自主性：稀少但存在

### 领域分布
```
软件工程：~50%
商业智能：<5%
客户服务：<5%
销售/金融/电商：各<3%
```

## 设计启示

### 对智能体开发者
1. **实现主动暂停机制**：让智能体在不确定时主动请求澄清
2. **设计渐进信任系统**：允许用户逐步增加自主性
3. **提供多种监督模式**：支持逐步批准和放手+介入两种策略

### 对产品设计
1. **默认保守**：新用户默认需要手动批准
2. **可配置自主性**：让经验用户可以调整
3. **透明的中断机制**：让用户随时可以介入

### 对安全策略
1. **监控高风险操作**：即使比例小，后果可能严重
2. **关注新兴领域**：医疗、金融、网络安全
3. **建立可逆性检查**：标记不可逆操作
