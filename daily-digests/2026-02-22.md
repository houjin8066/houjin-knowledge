## 📚 主题分类

### 一、多智能体系统架构

**市场数据**:
- Gartner: 2024-2025 多智能体系统咨询量增长 1,445%
- AI Agent 市场: 2025年 $7.63B → 2033年 $182.97B（CAGR 49.6%）
- 预计 2026 年底 40% 企业应用将包含任务特定 AI 智能体

**核心角色分工**:
- Planner（规划者）→ Executor（执行者）→ Verifier（验证者）→ Optimizer（优化者）
- 明确角色定义可降低任务失败率 35%

**三大架构模式**:
| 模式 | 适用场景 |
|------|----------|
| Sequential Pipeline | 清晰交接的工作流 |
| Coordinator/Dispatcher | 分诊系统 |
| Parallel Processing | 速度优先、任务独立 |

**2026 主流框架对比**:
| 框架 | 最佳场景 |
|------|----------|
| LangGraph | 复杂有状态工作流 |
| CrewAI | 角色协作团队 |
| AutoGen | 对话式多智能体 |
| SmolAgents | 代码优先开发 |

**关键协议**:
- ACP (Agent Communication Protocol) - 标准化消息格式
- MCP v2.1 - Agent 访问外部工具的标准协议
- A2A Protocol - 无监督 Agent 协作

### 二、本地推理生态

**隐私架构原则**:
> "Policy is a promise. Architecture is a guarantee."
> 政策是承诺，架构才是保证。

**本地推理成熟度**:
- 完整 ambient AI pipeline 已可本地运行
- 实时 STT、语义记忆、对话推理、TTS
- 一次性硬件购买，无按查询收费

**Taalas 专用硬件**:
- 17K tokens/sec（比 SOTA 快 10x）
- 成本降低 20x，功耗降低 10x
- 首款产品：硬连线 Llama 3.1 8B

### 三、智能体问责框架

**Human Root of Trust** 核心原则:
> "Every agent must trace to a human"（每个智能体必须追溯到人类）

六步信任链架构，为监管、审计、问责提供框架基础。

### 四、生产实践案例

**Stripe Minions**:
- 内部编码智能体，每周合并超过 1000 个 PR
- 人类审核代码，minions 从头到尾编写
- 证明智能体编码已可大规模应用

**Cord 框架**:
- 树状智能体协调，~500 行 Python
- spawn vs fork 原语：spawn 创建干净上下文，fork 继承兄弟结果
- 基于 Claude Code CLI + SQLite + MCP
