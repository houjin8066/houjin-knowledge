## 🧠 技术深度

### Agent 设计模式（Anthropic 最佳实践）

**核心原则**: 简单优于复杂，最成功的Agent实现用简单可组合模式

**五大 Workflow 模式**:
1. **Prompt Chaining** - 顺序步骤，用延迟换准确性
2. **Routing** - 输入分类导向专门任务
3. **Parallelization** - 拆分独立子任务并行执行
4. **Orchestrator-Workers** - 中央LLM动态分解委派
5. **Evaluator-Optimizer** - 生成-评估-迭代循环

**Agent vs Workflow**: 
- Workflow = 预定义代码路径编排
- Agent = LLM动态控制流程和工具

### 协议标准化

**MCP (Model Context Protocol)**
- Anthropic 开发，已捐赠 Linux Foundation
- 定位：AI模型与工具/数据源的标准化连接（"USB-C for AI"）
- 生态：10,000+ MCP servers
- 重大更新：MCP Apps (SEP-1865) 支持交互式UI

**A2A (Agent-to-Agent Protocol)**
- Google 开发
- 定位：独立AI Agent之间的通信协议
- 与 Google ADK 深度集成

**关键洞察**: MCP和A2A是互补的协议栈层级，不是竞争关系
- MCP = 垂直整合（工具访问）
- A2A = 水平协作（Agent通信）

## 💡 实践建议

1. **从简单开始** - 先用LLM API直接调用，很多模式几行代码就能实现
2. **理解底层** - 使用框架时确保理解底层代码
3. **沙箱测试** - Agent自主性意味着更高成本和错误累积风险
4. **协议选择** - 工具连接用MCP，Agent协作用A2A
