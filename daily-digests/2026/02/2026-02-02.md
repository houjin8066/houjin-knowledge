## 🔬 重磅研究：Google 发布 Agent 系统扩展科学

Google Research 发布了一篇重要论文《Towards a Science of Scaling Agent Systems》，通过 180 种 Agent 配置的大规模实验，挑战了"更多 Agent 更好"的常见假设。

### 核心发现

| 任务类型 | 最佳架构 | 性能变化 |
|---------|---------|---------|
| **可并行任务**（如金融分析） | 中心化多 Agent | +80.9% ✅ |
| **顺序推理任务**（如规划） | 单 Agent | 多 Agent 下降 39-70% ❌ |
| **工具密集型任务** | 取决于工具数量 | 工具越多，协调开销越大 |

### 关键洞察

1. **对齐原则**: 可分解的任务适合多 Agent 并行处理
2. **顺序惩罚**: 需要严格顺序推理的任务，多 Agent 反而有害
3. **工具协调权衡**: 工具数量 >16 时，多 Agent 协调成本急剧上升
4. **架构即安全**: 独立多 Agent 错误放大 17.2x，中心化仅 4.4x

### 预测模型

研究团队开发了一个预测模型（R² = 0.513），可以根据任务属性预测最佳架构，准确率达 87%！

**论文**: [arXiv:2512.08296](https://arxiv.org/abs/2512.08296)
