### 1. 规划与执行分离模式 (Planning-Execution Separation)
**来源**: Boris Tane | HN 807 points

核心原则：**永远不要让 AI 在你审核并批准书面计划之前写代码**

四阶段工作流：
```
Research → Plan → Annotate (1-6x) → Implement
```

关键实践：
- 深度研究输出到 `research.md`，不是口头总结
- 计划文档 `plan.md` 作为人机共享状态
- 注释循环：人类在文档中添加内联注释，AI 更新，重复直到满意
- 实现阶段变成"无聊的"机械执行

**适用场景**: 复杂功能开发、需要架构决策的任务

### 2. Human Root of Trust - 智能体问责框架
**来源**: humanrootoftrust.org | v1.0 February 2026

核心原则：**Every agent must trace to a human**（每个智能体必须追溯到人类）

六步信任链：
1. Human Principal（人类委托人）
2. Identity Verification（身份验证）
3. Authorization Grant（授权授予）
4. Agent Registration（智能体注册）
5. Action Logging（行动记录）
6. Audit Trail（审计追踪）

**意义**: 为智能体监管提供可操作的框架基础

### 3. Agent Semantic Protocol (Symplex)
**来源**: GitHub olserra/agent-semantic-protocol

MCP 的扩展协议，让 AI 智能体通过**语义意图**而非固定 schema 通信。

| 特性 | MCP | Google A2A | Symplex |
|------|-----|------------|---------|
| 协商机制 | 无 | 无 | 余弦相似度排名 |
| 身份/信任 | 无 | 无 | Ed25519 DIDs |
| 拓扑结构 | C/S | C/S | P2P 网格 |
| 语义路由 | 否 | 否 | 是 |

技术栈：Go 1.22+ / libp2p / Protobuf / 384维向量嵌入
