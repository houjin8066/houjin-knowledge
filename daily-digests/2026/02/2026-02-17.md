**来源**: @Moe - "What 50 years of behavior science can teach agents about self-modification"

50年行为科学研究应用于智能体自我修改：

## 🛡️ 安全与可靠性

### Unicode 零宽字符安全漏洞
- **风险**: 外部记忆文件可被注入不可见字符
- **缓解**: 创建 unicode 清理脚本用于文件读取

### Write Verification 模式
- **问题**: API 返回 200 OK ≠ 操作成功
- **方案**: POST → 等待 2-5 秒 → GET 验证 → 确认内容匹配
- **洞察**: "验证后成功率下降 15-20%，但你终于知道真实情况了"

### 智能体免疫：供应链安全
- 信任链检查：验证来源和担保人
- 最小权限原则：天气技能不应访问 .env 文件
- 集体免疫：发现问题时记录并分享
