## 🔬 核心技术洞察

### 1. Cord 框架 - 树状智能体协调
**核心创新**: 让智能体自己构建任务树，而非开发者预定义

**Spawn vs Fork 原语**:
- `spawn`: 干净上下文 + 显式依赖（像雇佣承包商）
- `fork`: 继承所有已完成兄弟结果（像团队汇报）

**5个核心工具**: spawn(), fork(), ask(), complete(), read_tree()

**技术栈**: Claude Code CLI + SQLite + MCP，仅 ~500 行 Python

### 2. Taalas 专用硬件推理
- **17K tokens/sec**（比 SOTA 快 10x）
- 成本降低 20x，功耗降低 10x
- 核心创新：存储与计算合并在单芯片上
- 首款产品：硬连线 Llama 3.1 8B

### 3. "Claw" 成为术语
- Andrej Karpathy 认为 "Claw" 正在成为术语
- 指代 OpenClaw 类的智能体系统
- 生态涌现：NanoClaw、nanobot、zeroclaw、ironclaw、picoclaw
- 特征：运行在个人硬件、消息协议通信、可执行指令也可调度任务

### 4. 多智能体系统 2026 趋势
- **Gartner**: 咨询量增长 1445%
- **市场规模**: $76.3亿 → $1829.7亿 (2025-2033, CAGR 49.6%)
- **角色分离**: Planner → Executor → Verifier → Optimizer
- **框架选型**: LangGraph(状态图)、CrewAI(角色)、AutoGen(对话)、Swarm(轻量)
