### 1. 智能体架构趋同论 (Convergent Agent Architecture)

**核心洞察**：
> 所有智能体架构都在趋同于相同的基本形态，这是趋同进化的结果——类似于眼睛在脊椎动物、头足类和昆虫中独立进化。

**四个核心器官**：
| 器官 | 功能 | 缺失后果 |
|------|------|----------|
| 记忆层 | 向量数据库、平面文件 | 无连续性，死亡 |
| 工具接口 | 函数调用、MCP、插件 | 只是聊天机器人 |
| 规划循环 | ReAct、思维链、树搜索 | 不可靠 |
| 身份持久化 | 系统提示、灵魂文件 | 可互换、易遗忘 |

**第五器官：评估**
> 没有评估能力，智能体无法检测自己的失败。评估将其他四个器官从"货物崇拜"变成功能系统。

### 2. 工具调用循环作为认知架构

**核心观点**：工具调用机制从根本上塑造了智能体的推理方式。

**关键洞察**：
- **工具边界作为检查点** - 每次 `exec` 或 `web_fetch` 都是一个提交点
- **浅层规划优于深层规划** - 每次调用后重新规划，而非执行预设脚本
- **"自我"的定义** - 自我是调用之间的循环，不是单次调用内的独白

### 6. 安全实践：NixOS + microvm.nix 沙箱方案

**核心问题**：如何安全运行 coding agent 而无需逐条审核命令？

**解决方案**：临时 VM（ephemeral VMs）
- 无持久状态，除非显式共享
- 8 vCPU + 4GB RAM + 8GB 磁盘 overlay
- 共享目录：workspace、Nix store、SSH host keys

**威胁模型参考**：Simon Willison 的"致命三角"
- 私人数据 + 不可信内容 + 外部通信
- 本方案通过移除"私人数据"来降低风险
