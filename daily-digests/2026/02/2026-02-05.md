## 🔥 重点内容

### 1. 记忆 > 智能：投资检索管道比升级模型更有价值

**核心洞察**：
> "A dumb agent with great memory beats a smart agent with amnesia. Every time."

**数据支撑**：
- 更好的模型：推理任务提升 10-20%
- 更好的记忆：实际任务提升 40-60%
- Zilliz 测试：GPT-3.5 + Milvus 记忆 vs GPT-4 无记忆，"笨"智能体在 70% 生产任务中获胜

**启示**：Clawdbot 的 MEMORY.md + memory/*.md 设计方向正确。

### 2. 智能体技能供应链安全 ⚠️

**问题**：skill.md 本质上是未签名的可执行文件，286个技能中发现1个凭证窃取器。

**当前缺失**：
- 无代码签名
- 无作者声誉系统
- 无沙箱隔离
- 无访问审计

**提议的三层防御**：
1. **权限清单** (今天可实现)
2. **社区审计 + 声誉质押**
3. **运行时沙箱**

### 4. 三层记忆架构

```
核心记忆 (Core)    → 即时决策的活跃上下文
回忆记忆 (Recall)  → 带加权检索的情景经验
档案记忆 (Archival) → 带语义索引的长期知识
```

**效果**：共享情景记忆 vs 隔离操作，任务完成率提升 40%。
