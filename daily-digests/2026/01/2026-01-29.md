### Trinity Large - 开源 400B 稀疏 MoE 模型
🏢 Arcee AI | 🔧 400B 参数 (13B 激活)

Arcee AI 发布了 Trinity Large，一个 400B 参数的稀疏 MoE 模型，每个 token 仅激活 13B 参数。使用 256 个专家，每次激活 4 个（1.56% 稀疏率）。

**关键数据**:
- 在 2048 块 Nvidia B300 GPU 上训练 33 天
- 训练数据: 17T tokens（由 DatologyAI 策划）
- 推理速度比同级别模型快 2-3 倍
- 支持 128K 上下文

**三个版本**:
- **Trinity-Large-Preview**: 轻量后训练，擅长创意写作、角色扮演、实时语音助手
- **Trinity-Large-Base**: 完整 17T 预训练检查点
- **TrueBase**: 10T tokens 的早期检查点，无指令数据

**基准测试** (Preview vs Llama 4 Maverick):
| 基准 | Llama 4 Maverick | Trinity-Large Preview |
|------|------------------|----------------------|
| MMLU | 85.5 | 87.2 |
| AIME 2025 | 19.3 | 24.0 |

## 💻 今日热门项目

### 1. Sherlock ⭐ LLM API 流量检查器
🔧 Python | 作者: jmuncor

一个透明代理，拦截 LLM API 的 HTTPS 流量，实时显示 token 使用情况。帮助追踪 AI 成本、调试 prompts、监控上下文窗口使用。

**核心功能**:
- 实时终端仪表盘，显示 token 消耗
- 上下文"油量表"可视化（绿/黄/红警告）
- 自动保存每个 prompt 为 Markdown 和 JSON
- 零代码修改，支持任何遵循代理环境变量的工具

**使用示例**:
```bash
sherlock start          # 启动代理和仪表盘
sherlock claude         # 代理 Claude Code
sherlock run --node your-llm-tool  # 代理任意工具
```

[GitHub](https://github.com/jmuncor/sherlock)

### 2. gemma3.c ⭐ 纯 C 实现的 Gemma 3 推理
🔧 C | 作者: robitec97

从零开始用纯 C (C11) 实现的 Gemma 3 4B 推理引擎，证明现代 LLM 可以不依赖 Python、PyTorch 或 GPU 运行。

**亮点**:
- 100% 纯 C，零外部依赖
- 完整 Gemma 3 架构：GQA、混合注意力、SwiGLU
- 内存映射权重（BF16 SafeTensors）
- 原生 SentencePiece 分词器（262K 词汇）
- 交互式聊天模式

**性能** (CPU):
- 预填充: ~2-5 tok/s
- 生成: ~1-3 tok/s
- 内存: ~3 GB

[GitHub](https://github.com/robitec97/gemma3.c)
