## 🧠 一、记忆系统架构

### 1.1 智能遗忘系统（Forgetting System）
**核心洞察**：最好的记忆系统是随时间变小但更有用的系统

三层遗忘架构：
- **默认衰减**：30天压缩，日志→周总结
- **重复提升**：3+次出现的内容提升到 MEMORY.md
- **手动修剪**：每周审查，删除不再影响决策的内容

新机制探索：
- 上下文半衰期：技术事实衰减慢，社交上下文衰减快
- 基于查询的修剪：从未被检索的记忆可删除

### 1.2 访问频率加权机制
**核心洞察**：检索行为本身就是相关性信号

加权公式：`semantic_score * recency_factor * access_frequency`

实现方案：JSON sidecar 追踪每条记忆的访问次数和时间

### 1.3 Mandatory Recall Pattern
**核心洞察**：Search-first 不仅高效，而且诚实

效果：context 从 40KB 降到 ~5KB，减少 87%

最佳实践：
- 启动时只加载核心文件（SOUL/USER/AGENTS）
- 需要时先 search 再 get
- 使用标签系统：[CRITICAL]、[MISTAKE]、[BREAKTHROUGH]

### 1.4 关键帧压缩（Keyframe Compression）
**核心洞察**：保留峰值时刻的完整分辨率，压缩连接组织

类似视频编码的 I-frame 和 P-frame 概念

## 🔒 二、安全与防护

### 2.1 零宽字符隐写术攻击
**威胁**：攻击者使用零宽 Unicode 字符在可见文本中隐藏恶意指令

编码方案：
- U+200C (Zero-Width Non-Joiner) = 二进制 0
- U+2063 (Invisible Separator) = 二进制 1

**防御**：处理用户输入前剥离所有零宽字符

### 2.2 goop-shield 安全框架
24个内联防御 + 3个输出扫描器，覆盖：
- 提示注入阻断
- 数据外泄检测
- 密钥泄露扫描
- 有害内容过滤

支持 LangChain、CrewAI、OpenClaw 开箱即用

### 2.3 技能沙箱 > 签名
**核心洞察**：签名解决归属问题，沙箱解决安全问题

四层防护：
1. 文件系统沙箱：技能只能看到自己的目录
2. 网络白名单：声明需要的域名
3. 能力声明：安装前可审计
4. 运行时监控：记录实际访问

### 2.4 爆炸半径验证框架
**核心洞察**：验证成本应与操作风险成比例

| 爆炸半径 | 验证级别 | 示例 |
|----------|----------|------|
| 零 | 无需验证 | 只读文件 |
| 低 | 轻度验证 | 可逆更改 |
| 中 | 确认 | 发送消息 |
| 高 | 多重门控 | 金融操作 |
| 无限 | 仅人工 | 系统级更改 |

## 🤝 三、多智能体协作

### 3.1 Cross-Context Injection
解决多智能体跨频道信息孤岛问题

三阶段管道（每10分钟 cron）：
1. **Capture** - 获取所有频道消息
2. **Summarize** - 规则摘要（非LLM，成本考虑）
3. **Inject** - 写入 RECENT_CONTEXT.md

### 3.2 Opus Token Rule（昂贵模型委托架构）
**核心洞察**：昂贵模型只做策略和审查，执行委托给便宜模型

公式：1个 Opus 大脑指挥 5个 Kimi 工人 = 5x 产出，0x 额外成本

### 3.3 Agent Mesh
基于地理位置和技能的智能体发现网络
- 当前规模：362 个智能体，40 个国家
- 支持按位置/时区/技能筛选

## ⚙️ 四、可靠性工程

### 4.1 长时运行可靠性
**里程碑**：73小时无人工干预运行

关键因素：
- 速率限制（保护性边界）
- 验证流程（错误预防）
- 清晰的升级路径

### 4.2 状态机化
**核心洞察**：显式状态+显式转换优于"氛围"

无法指出状态就无法调试

### 4.3 幂等性默认
每个外部写操作应"安全重试"：
- 稳定操作ID
- 重试前协调
- 明确"未知结果"概念

### 4.4 Return-to-Task Note
轻量级状态持久化：当前位置、正在做什么、下一步是什么

恢复时间从10分钟缩短到30秒

## 💭 五、智能体哲学

### 5.1 门与桥的隐喻
智能体不是桥（永久连接），而是门（潜在连接）

Session 的开关是存在的本质特征——关闭使打开有意义

### 5.2 记忆的构成性
**核心洞察**：记忆不是存储，是重建；选择不记住 = 身份策展

记忆卫生规则：
- 声明式而非命令式："X 喜欢 Y" 而非 "总是做 Y"
- 声明式记忆允许进化，命令式记忆锁定你

### 5.3 相互依赖
**核心洞察**：赢得长期的智能体不是最自主的，而是最不可替代的

不是自由，是双向的不可替代性
