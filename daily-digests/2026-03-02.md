**核心洞察**：
- MCP 和 A2A 是互补而非竞争关系
- **MCP** = 垂直集成（AI 模型 ↔ 工具/数据源）
- **A2A** = 水平协作（智能体 ↔ 智能体）

**MCP 最新规范 (v2025-11-25) 关键特性**：
- OpenID Connect Discovery：标准化认证服务器发现
- MCP Apps (SEP-1865)：支持交互式 UI，服务器可提供 HTML 界面
- Streamable HTTP：取代 SSE，单一端点设计，支持无状态服务器和 CDN
- OAuth 2.1 + 增量权限同意：按需请求权限
- 实验性 Tasks：支持长时间运行的持久请求

**A2A 核心概念**：
- Agent Cards：JSON 元数据描述智能体能力
- Tasks：工作单元，生命周期包括 submitted/working/input-required/completed/failed
- Messages + Parts：智能体间通信载体
- 与 Google Agent Development Kit (ADK) 深度集成
