# Pi-Mono - AI Agent 工具包

- **GitHub**: https://github.com/badlogic/pi-mono
- **作者**: badlogic
- **语言**: TypeScript
- **发现日期**: 2026-01-28

## 项目简介

Pi-Mono 是一个 AI Agent 工具包，包含：
- 编程 Agent CLI
- 统一 LLM API
- TUI & Web UI 库
- Slack 机器人
- vLLM pods

## 主要特性

- 构建 AI Agent 的工具集
- 管理 LLM 部署
- 支持多种界面（CLI、TUI、Web）

## 快速开始

```bash
npm install        # 安装依赖
npm run build      # 构建所有包
npm run check      # Lint、格式化、类型检查
./test.sh          # 运行测试
./pi-test.sh       # 从源码运行 pi
```
