## 项目简介

Kimi Code CLI 是一个运行在终端的 AI 编程助手，可以帮你完成软件开发任务和终端操作。它能读写代码、执行 shell 命令、搜索和获取网页，并在执行过程中自主规划和调整行动。

## 主要特性

- **Shell 命令模式**: 按 Ctrl-X 切换，直接在 CLI 中运行 shell 命令
- **IDE 集成 (ACP)**: 支持 Agent Client Protocol，可与 Zed、JetBrains 等 IDE 集成
- **Zsh 集成**: 通过 zsh-kimi-cli 插件增强 shell 体验
- **MCP 支持**: 支持 Model Context Protocol 工具

## 使用场景

- 终端内 AI 编程助手
- 代码阅读和编辑
- 自动化开发任务
- 与 IDE 协同工作

## 快速开始

```bash
# 安装
pip install kimi-cli

# 运行
kimi
```
