# MemU - 7×24 主动记忆框架

- **GitHub**: https://github.com/NevaMind-AI/memU
- **作者**: NevaMind-AI
- **语言**: Python
- **发现日期**: 2026-01-28

## 项目简介

MemU 是一个 7×24 主动记忆框架，能够持续学习、预测和适应。它将被动的 LLM 后端转变为具有"始终在线"记忆的智能代理，能够主动呈现洞察、预测需求，并在没有明确查询的情况下演化上下文。

## 核心能力

| 能力 | 描述 |
|------|------|
| 🔄 持续学习 | 7×24 从每次交互中提取记忆 |
| 🎯 主动检索 | 在被询问之前预测信息需求 |
| 🧠 上下文演化 | 记忆结构根据使用模式实时适应 |
| 🔍 双重智能 | 快速嵌入召回 + 深度 LLM 推理 |
| 🎨 多模态感知 | 跨文本、图像、音频、视频的统一记忆 |

## 与传统 RAG 的区别

| 传统 RAG | MemU 主动记忆 |
|----------|---------------|
| ❌ 等待明确查询 | ✅ 持续监控上下文 |
| ❌ 被动信息检索 | ✅ 预测信息需求 |
| ❌ 静态知识库 | ✅ 自演化记忆结构 |
| ❌ 一次性处理 | ✅ 始终在线学习管道 |

## 使用场景

- AI Agent 的长期记忆
- 个人助手的上下文理解
- 主动式信息推送
- 跨会话的知识积累
